# Decisions

A scannable index of specific decisions made while building this, in roughly the order they came up.
Each entry is deliberately short -- full reasoning and the live-verification evidence behind it is in
[ROADMAP.md](ROADMAP.md), linked where it's worth the detail. The five foundational decisions (D1-D5)
are described at length in [ARCHITECTURE.md](ARCHITECTURE.md); they're indexed here too for
completeness.

| # | Decision | Why | Alternative considered |
|---|---|---|---|
| D1 | Pure domain functions compute every number; tools only orchestrate I/O | A wrong number is a domain bug, findable and unit-testable without a model or a mock server in the loop | Computing inline in tools -- rejected: couples correctness to I/O, harder to test in isolation |
| D2 | Ports as `typing.Protocol`, not ABCs; env-driven driver selection | Structural typing needs no inheritance; `HRIS_DRIVER=memory` gets zero-credential tests/demo for free | ABC base classes -- rejected: forces adapters into a class hierarchy they don't need |
| D3 | Two-phase leave requests: signed preview token, re-verified at submit | A signature proves nothing changed *the token*; re-deriving every number at submit catches what changed in the world since preview | Trusting the signed values outright -- rejected: a stale-but-validly-signed preview could submit against an outdated balance |
| D4 | Idempotency via a SQLite `PRIMARY KEY` insert race | The insert itself is the concurrency gate -- no separate check-then-write race window | An in-memory lock -- rejected: doesn't survive a process restart, doesn't work across workers |
| D5 | Every tool failure is a structured `ToolError`, never a bare exception | `code` is machine-branchable, `recovery_hint` is written for the model to act on | Raising and letting a global handler translate -- rejected: loses the per-failure recovery hint |
| -- | KSA sick leave second tier is 75% pay, not 50% | An initial AI-search summary was wrong; corrected against Article 117 and cross-checked | -- |
| -- | Egypt annual leave follows Law 14/2025, not the more commonly-cited 2003 law | The 2003 figure (21 days after 6 months) describes a superseded law; verified the new law took effect 2025-09-01 | -- |
| -- | Hijri epoch constant is 1948439, not the commonly-cited 1948440 | Verified against two independent reference dates; the off-by-one would misdate every conversion | -- |
| -- | Gratuity: KSA and UAE fully modelled, Egypt retirement-only, Jordan not modelled at all | Confident, citable sources exist for the first two; Egypt's non-retirement compensation and Jordan's SSC-dependent rules don't, and a wrong severance figure stated confidently is worse than a refusal | See ROADMAP.md "Gratuity: modelled where the law is confident, refused where it isn't" |
| -- | UAE gratuity is reason-independent under current law | Verified live: the pre-2022 law's misconduct-forfeits-gratuity rule was repealed; several still-current-looking sources conflate the two | -- |
| -- | BM25 (`rank_bm25`) for SOP retrieval, with a documented precision ceiling on a small corpus | Pre-approved dependency; simple, no embeddings/vector store needed at ~56 chunks | Full semantic search -- rejected as overkill for corpus size; the false-positive risk is disclosed, not hidden |
| -- | Cross-language section pairing is positional, not title-based | Arabic and English section titles are themselves translated ("What It Is" / "ما هي") -- a title string can never be a cross-language join key | -- |
| -- | Google Sheets: raw `httpx` + `google-auth` for JWT signing, not `google-api-python-client`/`gspread` | Avoids a second HTTP stack (both alternatives are built on `requests`) for what is, underneath, two REST calls | The official heavier SDKs -- rejected: RSA-SHA256 signing is the one piece worth not hand-rolling, everything else is a thin wrapper this project already does itself for every other vendor |
| -- | `list_direct_reports` returns ids only; `list_employees_by_country` returns full records | Every caller of the first only needs an id set to filter something else by; every caller of the second needs every field on every result | Symmetric full-record returns everywhere -- rejected: would cost id-only callers N extra fetches they never asked for |
| -- | Gemini for the `/chat` LLM, not Anthropic or OpenAI | The actual requirement was "free yet reliable" -- Gemini has a genuine sustained free tier; the other two require a paid key | OpenRouter free-tier models, local Ollama -- considered less reliable/more setup-dependent for a live review |
| -- | Gemini adapter built against `generate_content` + manual history, not the newer Interactions API | Every type this adapter constructs was verified by direct construction against the installed SDK; the Interactions API's contract couldn't be verified without a live key | The newer API -- rejected for this build specifically due to unverifiable risk, not because it's wrong |
| -- | `GEMINI_MODEL` is a setting, not a hardcoded literal | `gemini-2.5-flash` (the default) is confirmed free-tier eligible now but shuts down 2026-10-16 -- a fact known to expire | Google's `-latest` alias -- rejected: documented history of silently 404ing when the version behind it changes |
| -- | `MockLLMAdapter` is keyword/regex routing, not an attempt at NLU | Turning free-form language into a tool call is the actual reasoning job a real model does; pretending otherwise would misrepresent what the mock is | -- |
| -- | Tool JSON schemas omit any parameter that would let the model claim a different identity | Mirrors `decide_leave_request`'s existing server-side authorization check: an injected "act as emp-999" is harmless if the model was never given a parameter that could carry it | Trusting an LLM-supplied employee_id with a server-side check after the fact -- rejected: strictly more attack surface for no benefit |
| -- | Idempotency keys are derived from the tool-call id, never model-supplied | Same reasoning as identity binding -- this is exactly the class of value D1 says a model shouldn't invent | -- |
| -- | `check_same_thread=False` on every SQLite connection | Found live: `TestClient`'s thread-bridging portal reused a singleton connection across threads and crashed; every access here is already sequential, so only Python's same-thread check needed disabling, not SQLite's own locking | -- |
| -- | One shared `company_time.py`, not three private `Asia/Riyadh` constants | A write (`submit_daily_checkin`) and a read (`chat.py`'s `as_of`) using different timezone logic silently disagreed for part of every real day -- found live by an end-to-end test | -- |
| -- | Web portal is one static HTML file, inline CSS/JS, no framework | Explicit instruction ("function over polish," "no build step"); FastAPI serves it by reading the file per request, so an edit shows up on refresh with no build/watch step | A minimal frontend framework -- rejected as unnecessary for one page with one interaction |
| -- | `tzdata` added as a dependency | Windows has no system IANA timezone database for `zoneinfo` to read; this is a portability fix for a stdlib module already in use, not new capability | -- |
